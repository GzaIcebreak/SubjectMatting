# Q 中间处理修复

依据47例复测及9例逐阶段诊断。只修改Q路径，SAM2保持原实现。

设计：色键保留孔洞与多像素细节；近完全覆盖（98%）才算重复候选；同一对象的互补候选合并后再交给判断；自动色键保留所有碎片，不让语义框删掉文字；默认停止语义remove，因为框与颜色相似无法证明像素属于背景。Q专用trimap保护细枝局部中轴及已检测到的封闭孔。没有基于文件名、类别或特定坐标的分支。

验证：合成环形、小碎片、互补/相同掩码、细枝回归；现有测试；重新打包并跑47例，保存前后对照。云端识别具有波动，不把所有前后差异归因于代码。额外固定已缓存Qwen方案验证人像remove。

已知边界：色键无法区分与背景同色的白色牙齿/高光和真实孔；语义分割原本填实的孔不会被此修复自动恢复。复杂镂空需要原图分辨率下的内部背景建模和局部alpha求解，单纯换提示词不能保证恢复。
