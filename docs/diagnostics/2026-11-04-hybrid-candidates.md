# Q 双路组合实测

在 `feat/qwen-sam3` 中接入原 Q 流程 A 与 BiRefNet_lite + ViTMatte 候选 B，无训练。SAM2 路径未修改。应用仍为 `dist/抠图demo.app`，本地签名通过，包体约357 MiB。

## 决策

- 先检查目标框之外的新增内容、整块目标丢失，以及同一目标中长距离空缺造成的结构断裂。这些是本地否决条件，不能被 Qwen 的肯定评价覆盖。
- 其余明显分歧使用原图、A/B合成图和最多四处新增/删除局部进行视觉评审。完整、目标一致、删除有依据且高置信时才采用B；光学材质、歧义、调用失败时保留A。
- B内部仅恢复被ViTMatte削弱的BiRefNet高置信细线，不与SAM3掩码直接取并集。所有规则不读取案例编号或文件名。
- 保守保护会保留A已有缺陷，视觉评审也可能幻觉，不能保证每张图不退步。

## 47例打包应用复测

使用实际包内 `matting-worker-q` 和C++动态库，串行执行报告提取的47张输入。全部47张导出，17张保留A，30张选B。**30是选择次数，不是改善数量或准确率。**每张保存同次A/B/最终PNG、目标框、规则指标、评审原文和导出SHA256。报告另外展示上一轮App输出，避免把Qwen重新识别的波动归因于组合器。

本机端到端中位数34.8秒，总计27.5分钟，范围8.3–64.6秒；包含网络和审计导出，系统负载未受控。组合比单路增加了模型推理和评审成本。

重点保护结果：

| 案例 | 结果 |
| --- | --- |
| 17摊位 | B丢失中间主体，只剩屋顶/招牌；结构连续性检查拒绝B。最终与上一轮App逐像素相同。 |
| 20梯田 | 保留A；最终与上一轮App逐像素相同。 |
| 10线香、43水壶、41香水瓶 | 均保留本次A；与上一轮存在少量边缘差异，alpha平均绝对差约0.069、0.072、0.072/255。10本身未正确提取烟雾，不能计作烟雾抠图成功。 |

目视可见03铁丝篮、11人物、21单车、45白鞋、46植物孔洞等有改善；34恢复了原色键误删的狗脸部位。02修复部分金属表面的误透明，但密集滤孔仍未可靠分离。

已知失败：05把伞下背景误认成底座并接受B；19多留一块路边地面；00笼内背景仍未去净。13在本次原流程中就改变了目标范围，桌面被排除，反映云端识别不稳定。评审的自然语言理由也会与图像事实相反，例如把缺失部件说成保留，不能作为人工评分。

这些输入是HTML报告内的缩小截图，不是全分辨率原始图片，也没有真值alpha。此批仅用于对照与发现失败，不能宣称泛化准确率。
