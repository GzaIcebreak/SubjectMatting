## 耗时（稳态，单张，长边 ≤1024 处理）

| | 平均 | 最快–最慢 | 各阶段平均 |
|---|---|---|---|
| **A** BiRefNet_lite + SAM2.1-tiny + ViTMatte-S | **3.68s** | 3.34–4.15s | 显著性 2.66 · SAM2 0.62 · 抠图 0.40 |
| **C** EfficientSAM3 EV-M + ViTMatte-S（自动词表） | **4.88s** | 4.58–5.47s | 图像编码 0.51 · 文本×6 3.94 · 抠图 0.43 |
| **C**（手动指定 1 个提示） | ~1.7s | | 图像编码 0.5 · 文本×1 0.7 · 抠图 0.5 |

模型加载：ViTMatte 7.7s（两个方案共用），A 3.3s，C 2.0s（从本地缓存加载）。
权重体积：A 约 440MB（SAM2.1-tiny 156MB + BiRefNet_lite 178MB + ViTMatte 103MB），C 约 570MB（EV-M 468MB + ViTMatte）。

## 结论

- **方案 A 更稳更快**：每张都抠对了，平均 3.7s，主要靠 BiRefNet_lite 的显著性定位。SAM2-tiny 负责收紧边界，ViTMatte 负责发丝。
  瓶颈在显著性（2.7s）；如果能接受偶尔失败，可降到 512 输入，约快 1s。
- **方案 C 在已知类别时更有价值**：自动词表模式比 A 慢约 1.2s，且语义判断不可靠（熊被判成 person）。
  但**手动给一个提示词时只要 ~1.7s**，适合"知道要抠什么类别"或"同一图里指定抠某一类"的场景。
- 两者的发丝质量都来自 ViTMatte-S，差别主要在主体 mask 的选择和完整度上。
